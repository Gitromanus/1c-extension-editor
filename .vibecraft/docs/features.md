# 1C Extension Editor

## Цель проекта

Дать пользователю веб-приложение для работы с файлами расширений 1С (.cfe): загрузка и распаковка файла, просмотр структуры и содержимого модулей, внесение правок в код и обратная упаковка в .cfe с возможностью скачать результат. Вся обработка выполняется локально в браузере без внешних серверов.

## Основные возможности

### Загрузка и распаковка расширения

- **Цель:** Пользователь хочет открыть файл расширения 1С (.cfe) для работы с его содержимым.
- **Описание:** Пользователь выбирает файл .cfe, приложение распаковывает его (по логике формата v8unpack) и переходит к рабочему просмотру содержимого.
- **Критерии приёмки:**
  - Файл .cfe успешно распаковывается и его содержимое доступно для просмотра
  - При ошибке или неверном формате показывается понятное сообщение

### Просмотр структуры файлов

- **Цель:** Пользователь хочет видеть файловую структуру распакованного расширения.
- **Описание:** Содержимое показывается в виде дерева/списка папок и файлов с навигацией по ним. Для нативных бинарных контейнеров 1С имена папок и модулей декодируются в читаемые названия (имя расширения, типы метаданных, имена объектов, формы, модули, а также модули самой конфигурации — модуль приложения, сеанса и внешнего соединения) как в 1С.
- **Критерии приёмки:**
  - Структура расширения отображается в виде дерева папок и файлов
  - Пользователь может раскрывать папки и переходить к файлам
  - Имена папок и модулей нативных контейнеров 1С читаемы, а не GUID/бинарные

### Просмотр и редактирование кода

- **Цель:** Пользователь хочет открывать текстовые файлы расширения и вносить правки.
- **Описание:** Текстовые файлы (модули) открываются в редакторе с просмотром кода и возможностью редактирования. Код модулей 1С отображается с цветовой подсветкой синтаксиса на основе библиотеки highlight.js (встроенный язык «1C:Enterprise»): ключевые слова, строки, комментарии, числа, идентификаторы и директивы компиляции. Рабочая область зафиксирована по высоте окна: прокрутка выполняется только внутри дерева и области редактора, само основное окно не прокручивается.
- **Критерии приёмки:**
  - Текстовые файлы открываются с читаемым кодом
  - Код модулей 1С отображается с привычной цветовой подсветкой как в конфигураторе 1С
  - Пользователь может вносить и сохранять изменения в код
  - Бинарные/нетекстовые файлы корректно обрабатываются без искажений

### Упаковка и скачивание

- **Цель:** Пользователь хочет собрать изменённое расширение обратно в .cfe и получить файл.
- **Описание:** Приложение упаковывает текущее содержимое (с учётом правок) обратно в файл .cfe и предлагает скачать его. Возможность редактирования и обратной упаковки доступна как для файлов, представленных в виде ZIP-контейнера, так и для нативного бинарного контейнера 1С.
- **Критерии приёмки:**
  - Изменённое расширение упаковывается обратно в .cfe без потери данных
  - Скачанный файл доступен пользователю для использования

## Дополнительные заметки

- Приложение поддерживает два формата .cfe:
  - **ZIP-контейнер:** полная работа — просмотр, редактирование, обратная упаковка и скачивание.
  - **Нативный бинарный контейнер 1С (логика v8unpack):** просмотр содержимого (в том числе вложенных контейнеров и модулей на языке 1С) с читаемыми именами папок и модулей; пользователь может вносить правки в код модулей (модули объектов `Module.bsl`, а также модули самой конфигурации — модуль приложения, сеанса и внешнего соединения) и упаковывать изменённое содержимое обратно в .cfe. Файлы метаданных (скобкофайлы) редактированию не подлежат, чтобы не повредить структуру расширения.
- Формат распаковки/упаковки строится по подходам проекта v8unpack (https://github.com/saby-integration/v8unpack).
- Вся работа выполняется локально в браузере, данные не отправляются на внешние серверы.
- Пользователь может переключаться между светлой и тёмной темой через переключатель в шапке приложения (по умолчанию тёмная, доступна система).
- Стиль интерфейса — строгий инструмент разработчика: плотная компоновка, акцент на читаемость кода и скорость работы.
